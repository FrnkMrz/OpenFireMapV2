## 用途 {#wofuer}
纸质地图无需网络或电池，可用于消防站、车辆、训练和预案。与[导出](../export/)不同，城区地图带固定比例尺、网格和街道索引。
## 条件 {#voraussetzungen}
使用电脑并选择德国境内范围；当前底图仅覆盖德国。打开[城区地图工具](/ortsplan/)，移动地图并框选。
:::note 界面仅德语
工具目前只有德语界面，设置保存在浏览器。
:::
## 步骤1：范围和格式 {#schritt-1}
:::figure plan-1 frame=browser
范围、纸张、方向、布局和比例尺设置。
:::
拖动边框设置范围，选自由形状或匹配纸张比例。纸张为A4至A1，可横向或纵向。图例、比例尺和索引可放在地图周围。
:::tip 比例尺建议
市中心可选1:2,000–1:4,000，整个村庄可选1:7,500–1:10,000。拥挤时选大纸张。
:::
## 步骤2：内容 {#schritt-2}
:::figure plan-2 frame=browser
标题与地图内容设置。
:::
设置地点名和标题，选择消防对象、道路、市镇边界及索引，也可调整分辨率、索引列数和字号。
:::tip 分辨率
普通打印用150dpi，大幅面用300dpi，后者文件更大。
:::
## 步骤3：排版 {#schritt-3}
:::figure plan-3 frame=browser
地图、图例、比例尺、指北针和索引预览。
:::
可自动排版或手动拖动区块，也可用<kbd>Tab</kbd>和方向键移动。地图可调整大小并保持比例尺。最后点击创建。
## 成品 {#blatt}
:::figure plan-sheet frame=browser
带网格、图例、比例尺和索引的成图。
:::
生成后可更改设置并重新载入。索引太长时会分页。保存为 PDF 或 PNG。
## 打印 {#drucken}
:::steps
1. 打开 PDF 并打印。
2. 选择实际大小或100%，不要适合页面。
3. 选择设置的纸张尺寸。
4. 打印后检查比例尺。
:::
## 须知 {#wissen}
数据日期会打印在地图上。数据有较大变化时请重新生成。保留 OSM 署名。缺少的消防栓可[添加到 OSM](../contribute/)。
:::warn 非官方文件
城区地图不能替代市政府或供水公司的资料。重要信息请现场核实。
:::
