## 背景地图 {#hintergrund}
:::figure layers frame=plain
电脑上的地图图层菜单。
:::
| 背景 | 用途 |
|---|---|
| 标准（Voyager） | 日常使用、门牌号 |
| 打印（Light） | 适合打印，符号醒目 |
| 夜间（Dark） | 减少夜间眩光 |
| 卫星（Esri） | 查看建筑与入口 |
| 地形（OSM） | 地形、水域、等高线 |
| OSM（Intl） | 标准 OSM 样式 |
| OSM（DE Style） | 德国样式 |
| Bavaria Base/Aerial | 巴伐利亚官方地图与航拍图 |
所选背景用于分享和[导出](../export/)。
:::tip 门牌号
标准和 OSM 在缩放17、18时显示门牌号。
:::
## 缩放级别 {#zoom}
| 缩放 | 内容 |
|---|---|
| 12以下 | 无对象 |
| 12–13 | 消防站圆点 |
| 14起 | 消防站符号、市镇边界 |
| 15–16 | 消防栓、水源、AED |
| 16起 | 轻触显示100米圆 |
| 17起 | 带字母符号，可键盘选择 |
| 18 | 悬停查看详情 |
## 颜色和符号 {#symbole}
红色为消防栓：**U**地下式、**O**柱式、**Ø**干式。蓝色为消防水源，绿色为 AED，消防站有独立建筑符号。缩放17起，5米内对象会聚合显示数量。[地图符号](/symbols/)列出 OSM 标签。
:::note 数据来源
类型、口径和编号来自 OSM。类型未记录时显示无字母红点。[添加对象](../contribute/)。
:::
