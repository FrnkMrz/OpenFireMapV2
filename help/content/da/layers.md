## Baggrundskort {#hintergrund}

:::figure layers frame=plain
Menuen “Map layers” på en computer.
:::

| Baggrund | God til |
|---|---|
| **Standard (Voyager)** | daglig brug og tydelige gader |
| **Print (Light)** | udskrift; symbolerne træder tydeligt frem |
| **Night (Dark)** | mørke og mindre blænding |
| **Satellite (Esri)** | bygninger, indkørsler og vegetation |
| **Topographic (OSM)** | terræn, stier og vand |
| **OSM (Intl/DE)** | OpenStreetMap-kortstile |
| **Bavaria Base/Aerial** | officielle kort og luftfoto i Bayern |

Baggrundskortet følger med delingslinket og bruges ved [eksport](../export/).

## Zoomniveauer {#zoom}

| Zoomniveau | Det vises |
|---|---|
| under 12 | ingen objekter |
| 12–13 | brandstationer som prikker |
| fra 14 | stationssymboler og kommunegrænser |
| 15–16 | brandhaner, vandforsyning og hjertestartere som prikker |
| fra 16 | radius på 100 meter ved tryk |
| fra 17 | symboler med bogstaver |
| 18 | detaljer ved pegebevægelse |

## Farver og symboler {#symbole}

- **Rød:** brandhaner. **U** er underjordisk, **O** stander, **Ø** tør brandhane.
- **Blå:** vandforsyning, f.eks. branddamme, cisterner og sugepunkter.
- **Grøn:** hjertestartere (AED).
- Brandstationer har deres eget bygningssymbol.

Flere objekter inden for 5 meter kan grupperes. Siden [kortsymboler](/symbols/) viser alle symboler og OpenStreetMap-tags. Type, diameter og nummer kommer fra OpenStreetMap. Se [Bidrag](../contribute/) for at tilføje oplysninger.
