## Hannergrondkaarten {#hintergrund}
:::figure layers frame=plain
De Menü „Kaarteschichten“ um Computer.
:::
| Hannergrond | Gutt fir |
|---|---|
| Standard (Voyager) | Alldag, Hausnummeren ab Zoom 17 |
| Drock (Light) | Drécken, hell a kloer Symboler |
| Nuecht (Dark) | Nuets, manner Blendung |
| Satellit (Esri) | Gebaier an Zoufluchtsweeër erkennen |
| Topographesch (OSM) | Terrain, Waasser, Weeër |
| OSM (Intl) | Gewinnten OSM-Stil |
| OSM (DE Style) | Däitschen OSM-Stil |
| Bavaria Base/Aerial | Offiziell Kaart a Loftbild vu Bayern |
Déi gewielte Schicht gëtt och gedeelt an exportéiert.
:::tip Hausnummeren
Standard an OSM weisen Hausnummeren op Zoom 17 an 18.
:::
## Zoomstufen {#zoom}
| Zoom | Wat erschéngt |
|---|---|

| 12–13 | Pompjeesgebaier als Punkten |
| ab 14 | Symboler a Gemengegrenzen |
| 15–16 | Hydranten, Waasserstellen an AEDen |
| ab 16 | 100-m-Ëmkrees beim Tippen |
| ab 17 | Buschtafsymboler, och mat Tastatur |
| 18 | Detailer beim Iwwerfaren |
## Faarwen a Symboler {#symbole}
- **Rout:** Hydranten. **U** ënnerierdesch, **O** Sailhydrant, **Ø** Dréchenhydrant.
- **Blo:** Waasserstellen wéi Weieren, Zisternen a Saugstellen.
- **Gréng:** AED.
- **Pompjeesgebaier:** eegent Gebaier-Symbol.
Objeten bannent 5 Meter gi vun Zoom 17 u gruppéiert. [Kaartesymboler](/symbols/) weisen OSM-Tags.
:::note Quell vun den Detailer
Typ, Duerchmiesser an Nummer kommen aus OSM. Ouni Typ gëtt e roude Punkt ouni Buschtaf gewisen. [Matmaachen](../contribute/).
:::
