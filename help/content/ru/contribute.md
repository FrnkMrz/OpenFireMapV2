## Перед началом {#vorher}

OpenFireMap показывает данные [OpenStreetMap](https://www.openstreetmap.org/) (OSM). Редактировать нужно в OpenStreetMap, а не в OpenFireMap. Сначала создайте аккаунт:

:::steps
1. На [openstreetmap.org](https://www.openstreetmap.org/user/new) выберите **Sign Up**.
2. Укажите имя пользователя, адрес электронной почты и пароль, затем подтвердите почту.
3. Войдите в инструменты ниже с этой учётной записью.
:::

:::warn Три правила
- **Добавляйте только то, что лично увидели на месте.** Проверьте положение и тип гидранта.
- **Не копируйте данные с чужих планов.** Планы водоканалов и муниципалитетов защищены авторским правом. Используйте их только с явного разрешения.
- **При сохранении кратко опишите изменения**, например: «Добавлены гидранты на Главной улице».
:::

Пожарные команды Германии могут воспользоваться инструкцией по проверке гидрантов своего района во время учений или обхода города; она доступна только на немецком: [Für Feuerwehren](/help/fire-brigades/).

## Какой инструмент выбрать? {#werkzeug}

| Ситуация | Инструмент | Почему |
|---|---|---|
| вы на месте с телефоном и хотите быстро добавить гидрант | **Hydrantenjäger** | создан для гидрантов, ставит точку по компасу, мало полей |
| хотите добавлять объекты по пути | **StreetComplete** или **Every Door** | задают вопросы об объектах поблизости |
| работаете на компьютере с отдельными местами | **редактор iD** | работает в браузере openstreetmap.org, установка не нужна |
| опытный пользователь и редактируете много объектов | **JOSM** (компьютер) или **Vespucci** (Android) | полный контроль над тегами |

## Hydrantenjäger {#hydrantenjaeger}

[Hydrantenjäger](https://hydrantenjaeger.de/) — веб-приложение для телефона, созданное для этой задачи:

:::steps
1. Войдите с аккаунтом OpenStreetMap.
2. Встаньте примерно в трёх метрах перед гидрантом и наведите на него телефон. Приложение поставит точку по GPS и компасу.
3. Выберите тип и положение; диаметр и номер указывайте, только если уверены.
4. Загрузите запись. Готово.
:::

Подробное описание типов гидрантов есть в [справке Hydrantenjäger](https://hydrantenjaeger.de/help/).

## StreetComplete или Every Door {#apps}

- **[StreetComplete](https://streetcomplete.app/)** (Android, iOS) задаёт вопросы об объектах рядом, например: «Какой это тип пожарного гидранта?». Ответьте нажатием. Приложение в основном помогает дополнить сведения об уже существующих объектах.
- **[Every Door](https://every-door.app/)** (Android, iOS) предназначено для добавления точек. Нажмите плюс, поставьте новую точку, выберите «Fire Hydrant» и заполните поля.

## Редактор iD в браузере {#id}

iD — стандартный редактор сайта openstreetmap.org.

:::steps
1. Откройте [openstreetmap.org](https://www.openstreetmap.org/), войдите и приблизьте карту к месту гидранта.
2. Нажмите **Edit** сверху. При первом запуске полезно пройти короткое знакомство с редактором.
3. Нажмите **Point** и поставьте точку точно на гидранте. Аэрофотоснимок поможет сориентироваться.
4. В поле поиска слева введите «hydrant» и выберите шаблон **Fire Hydrant**.
5. Заполните поля: **Type** (подземный, колонка, настенный, труба), **Position** (например, тротуар или проезжая часть), **Diameter** и **Reference**, если известны.
6. Нажмите **Save** справа вверху, оставьте краткий комментарий и нажмите **Upload**.
:::

:::tip Исправление имеющегося гидранта
Нажмите на существующий гидрант, измените поля слева и сохраните. Если точка стоит неверно, перетащите её. Удаляйте объект, только если на месте убедились, что его больше нет.
:::

## JOSM или Vespucci {#josm}

[JOSM](https://josm.openstreetmap.de/) — редактор для компьютера на Java, [Vespucci](https://vespucci.io/) — его аналог для Android. Они показывают все теги и подходят для больших задач, например обновления всех гидрантов после обхода района. Основные теги приведены ниже.

## Важные теги {#tags}

В OpenStreetMap объекты описываются тегами вида `key=value`. Шаблоны приложений задают их автоматически. При ручном вводе используйте:

| Объект | Тег | Значение |
|---|---|---|
| Гидрант | `emergency=fire_hydrant` | обязателен для каждого гидранта |
| | `fire_hydrant:type=underground` | подземный (также `pillar`, `wall`, `pipe`) |
| | `fire_hydrant:diameter=80` | номинальный диаметр DN, как на знаке |
| | `fire_hydrant:position=sidewalk` | положение (также `lane`, `parking_lot`, `green`) |
| | `ref=123` | номер гидранта, если есть |
| | `fire_hydrant:pressure=4` | давление в барах, если известно |
| Водоразборная точка | `emergency=suction_point` | место забора воды из водоёма |
| Резервуар | `emergency=water_tank` | цистерна или резервуар пожарной воды |
| Пожарный пруд | `emergency=fire_water_pond` | водоём для тушения пожаров |
| Дефибриллятор | `emergency=defibrillator` | плюс `indoor=yes/no`, `defibrillator:location=…`, `opening_hours=…` |
| Пожарная станция | `amenity=fire_station` | здание или территория пожарной службы |

На странице [значков карты](/symbols/) показано, как теги выглядят в OpenFireMap. Подробнее — в [вики OpenStreetMap](https://wiki.openstreetmap.org/wiki/Tag:emergency%3Dfire_hydrant).

## Когда появится изменение? {#anzeige}

После загрузки гидрант сразу сохраняется в OpenStreetMap. В OpenFireMap он появится, когда службы, откуда карта получает данные, обработают изменение. Обычно это происходит быстро, но точный срок не установлен. О задержках — в разделе [Данные и актуальность](../data/#verzoegerung).
