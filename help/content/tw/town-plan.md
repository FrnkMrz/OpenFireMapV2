## 城鎮圖用途 {#wofuer}

城鎮圖是供消防隊、訓練或車輛使用的列印版圖紙。與一般匯出不同，它具有固定比例尺、網格、圖例、指北箭頭和街道索引。目前僅支援德國地區。

## 開始使用精靈 {#voraussetzungen}

在電腦上從選單開啟 **Town plan**，拖曳矩形選取範圍。精靈會檢查大小，接著可選擇紙張與比例尺。

:::warn 範圍太大？
城鎮圖用於地方區域。若精靈提示，請縮小選取範圍。
:::

## 步驟 1：範圍與格式 {#schritt-1}

選取所需區域，然後設定紙張大小與比例尺。比例尺較大時範圍較小但細節更多；比例尺較小時涵蓋範圍較廣。選擇合適的紙張方向。

:::figure plan-1 frame=browser
步驟 1：地圖框選、紙張、方向、版面與比例尺。
:::

## 步驟 2：物件與圖例 {#schritt-2}

選擇要顯示的物件，例如消防栓、供水點、消防隊駐地、去顫器和行政區界線。圖例說明標記，街道索引協助查找街道名稱。

:::figure plan-2 frame=browser
步驟 2：圖紙上的文字與計畫圖內容。
:::

## 步驟 3：排版 {#schritt-3}

調整各項元素的位置：

- **標題：**點擊文字即可編輯。
- **圖例與比例尺：**可拖曳至空白區域。地圖會吸附至紙張邊緣，並保持在紙張範圍內。
- **地圖大小：**拖曳地圖右下角（鍵盤：<kbd>Alt</kbd> + 方向鍵）。比例尺不變，涵蓋範圍會增減。
- 啟用 **Blöcke dürfen auf der Karte liegen**，可將圖例和比例尺放在空白地圖區域，背景可選白色或透明。
- **Anordnung zurücksetzen** 可還原建議版面。

最後按 **Ortsplan erstellen**。

:::figure plan-3 frame=browser
含標題、地圖、圖例、比例尺、指北箭頭、資料來源與索引的預覽。
:::

## 完成的圖紙 {#blatt}

:::figure plan-sheet frame=browser
完成圖紙：含網格、圖例、比例尺、指北箭頭和街道索引。
:::

圖紙會以完整尺寸開啟。上方列可變更比例尺、紙張、解析度與文字，再按 **Neu laden** 套用。若街道索引無法放進同一頁，會接續到第二頁，圖紙上方也會提示。

- **PDF speichern：**以指定紙張大小儲存，適合列印。
- **PNG speichern：**儲存為圖片，例如放入簡報。

## 正確列印 {#drucken}

:::steps
1. 開啟 PDF 並選擇 **Print**。
2. 選擇 **Actual size** 或 **100%**，不要用「Fit to page」，才能維持正確比例尺。
3. 使用精靈中設定的紙張大小（A2、A1 通常需至印刷店列印）。
4. 列印後用尺檢查比例尺。
:::

## 注意事項 {#wissen}

- 資料時效取決於 OpenStreetMap，日期會印在圖紙上。城鎮有重大變更後請製作新圖。
- 「© OpenStreetMap contributors」會自動印上，必須保留。
- 若圖紙缺少消防栓，表示 OpenStreetMap 尚未記錄。請[新增資料](../contribute/)，下次製圖時就會顯示。

:::warn 非官方文件
城鎮圖不能取代供水單位或地方政府提供的計畫圖。重要資訊請至現場確認。
:::
