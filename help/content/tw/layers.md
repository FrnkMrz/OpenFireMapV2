## 底圖 {#hintergrund}

:::figure layers frame=plain
電腦上的「Map layers」選單。
:::

| 底圖 | 適用情境 |
|---|---|
| **Standard (Voyager)** | 日常使用：街道清楚，縮放 17 起顯示門牌 |
| **Print (Light)** | 列印與匯出：底色明亮，標記醒目 |
| **Night (Dark)** | 夜間及車內使用，減少眩光 |
| **Satellite (Esri)** | 現場定位：建物、車道與植被 |
| **Topographic (OSM)** | 城外地形、等高線、步道與水域 |
| **OSM (Intl)** | 熟悉的 OpenStreetMap 樣式 |
| **OSM (DE Style)** | 德國風格的 OpenStreetMap |
| **Bavaria Base** | 巴伐利亞測量機關的官方地圖，僅限巴伐利亞 |
| **Bavaria Aerial** | 官方航照圖，僅限巴伐利亞 |

分享連結會保留目前底圖，[匯出](../export/)也會使用它。

:::tip 查找門牌
縮放 17 和 18 時，Standard 與 OSM 會顯示門牌，方便將消防栓對應到地址。
:::

## 縮放層級 {#zoom}

OpenFireMap 只載入目前畫面需要的資料。狀態框會顯示縮放層級。

| 縮放層級 | 顯示內容 |
|---|---|
| 低於 12 | 尚無物件（狀態為「Standby」） |
| 12–13 | 消防隊駐地以點表示 |
| 14 起 | 駐地標記與行政區界線 |
| 15–16 | 消防栓、供水點與去顫器以彩色點表示 |
| 16 起 | 輕觸消防栓時顯示 100 公尺圓圈 |
| 17 起 | 帶字母的標記，可用鍵盤選取 |
| 18 | 滑鼠懸停時顯示詳細資料 |

## 顏色與標記 {#symbole}

顏色表示物件類別，標記中的字母表示類型：

- **紅色：**消防栓。**U** 代表地下式，**O** 代表地上柱式，**Ø** 代表乾式消防栓。牆式與其他類型有各自的符號。
- **藍色：**供水點，例如消防池、水槽、消防用水井或抽水點。
- **綠色：**自動體外心臟去顫器（AED）。
- **消防隊駐地**使用專屬建築標記。

縮放 17 起，距離在 5 公尺內的多個物件會被群組並顯示數量。

[地圖標記](/symbols/)頁面列出每個標記及其 OpenStreetMap 標籤，也適合想了解標記來源的地圖編輯者。

:::note 詳細資料來源
類型、口徑、編號等資訊均來自 OpenStreetMap。若未記錄消防栓類型，地圖會顯示沒有字母的紅點。如何新增資料請見[參與貢獻](../contribute/)。
:::
