## 背景地図 {#hintergrund}
:::figure layers frame=plain
パソコンの「地図レイヤー」メニュー。
:::
| 背景 | 用途 |
|---|---|
| **標準（Voyager）** | 日常利用、ズーム17から番地を表示 |
| **印刷（Light）** | 明るく、記号が見やすい |
| **夜間（Dark）** | 夜間や車内でまぶしさを抑える |
| **衛星（Esri）** | 建物や進入路を現地確認 |
| **地形（OSM）** | 地形、等高線、水域 |
| **OSM（Intl）** | 標準的なOpenStreetMap表示 |
| **OSM（DE Style）** | ドイツ向けOSM表示 |
| **Bavaria Base** | バイエルン州公式地図 |
| **Bavaria Aerial** | バイエルン州公式航空写真 |
共有リンクとエクスポートにも選択した背景が使われます。
:::tip 番地
標準とOSMではズーム17・18で番地が見られます。
:::

## ズームレベル {#zoom}
| ズーム | 表示 |
|---|---|
| 12未満 | 地物なし |
| 12～13 | 消防署を点で表示 |
| 14以上 | 消防署記号、市町村境界 |
| 15～16 | 消火栓、水源、AEDを表示 |
| 16以上 | タップで100m円 |
| 17以上 | 文字付き記号、キーボード選択 |
| 18 | マウスを重ねると詳細 |

## 色と記号 {#symbole}
- **赤：** 消火栓。**U**は地下式、**O**は地上式、**Ø**は乾式。壁面式などは別記号。
- **青：** 消防池、貯水槽、井戸、吸水地点など。
- **緑：** AED。
- **消防署：** 専用の建物記号。
ズーム17以上で5m以内に地物が複数あると、まとめて件数を表示します。[地図記号](/symbols/)にOSMタグ付き一覧があります。
:::note 詳細の出所
種類、口径、番号などはOpenStreetMapから取得します。種類が未登録なら文字のない赤い点です。[地物の追加](../contribute/)。
:::
