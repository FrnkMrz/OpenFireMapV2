## 用途 {#wofuer}
印刷地図は通信や電池が不要で、消防署の壁面、車両、訓練、事前計画に便利です。[通常のエクスポート](../export/)と異なり、固定縮尺、グリッド、道路索引があります。

## 必要なもの {#voraussetzungen}
- 最新ブラウザーを備えたパソコン。スマートフォンは画面が小さいため対象外です。
- ドイツ国内の範囲。現在の基図はドイツを対象とします。
[市街図アシスタント](/ortsplan/)を開き、地図を移動・ズームして枠を描きます。
:::note 画面はドイツ語
アシスタントは現在ドイツ語のみです。設定はブラウザーに保存されます。
:::

## ステップ1：範囲と形式 {#schritt-1}
:::figure plan-1 frame=browser
用紙、向き、配置、縮尺を選択。
:::
枠をドラッグして範囲を選びます。自由形状または用紙比率、A4～A1、横・縦を指定できます。凡例などは地図の上下左右または地図上に配置できます。縮尺は自動計算または一覧から選べます。
:::tip 縮尺
中心部は1:2,000～1:4,000、村全体は1:7,500～1:10,000が目安です。混雑する場合は大きな用紙を選びます。
:::

## ステップ2：内容 {#schritt-2}
:::figure plan-2 frame=browser
タイトルや地図の内容を指定。
:::
場所名と見出しを入力し、記号、道路種別、市町村境界、索引を選択します。解像度（96～300dpi）、索引列数、文字サイズも調整できます。
:::tip 解像度
通常は150dpi、大判や印刷所では300dpiを選びます。ファイルが大きくなります。
:::

## ステップ3：配置 {#schritt-3}
:::figure plan-3 frame=browser
タイトル、地図、凡例、縮尺、北矢印、出典、索引のプレビュー。
:::
自動配置のほか、「ブロックを自分で配置」で調整できます。ドラッグ、または<kbd>Tab</kbd>と矢印キーで移動します。地図の角で大きさを変えても縮尺は維持されます。最後に「市街図を作成」を押します。

## 完成した用紙 {#blatt}
:::figure plan-sheet frame=browser
グリッド、凡例、縮尺、北矢印、道路索引付きの完成図。
:::
完成後も用紙、縮尺、解像度、文字を変更できます。索引が収まらない場合は2ページ目に続きます。PDFまたはPNGで保存します。

## 印刷 {#drucken}
:::steps
1. PDFを開いて印刷します。
2. 「実際のサイズ」または100%を選び、「用紙に合わせる」は使いません。
3. アシスタントで選んだ用紙を指定します。
4. 印刷後、定規で縮尺バーを確認します。
:::

## 補足 {#wissen}
データ日付は用紙に印刷されます。大きな変更後は作り直してください。「© OpenStreetMap contributors」は必ず残してください。消火栓がなければ[OSMに登録](../contribute/)できます。
:::warn 公式資料ではありません
自治体や水道事業者の地図に代わるものではありません。重要な情報は現地で確認してください。
:::
