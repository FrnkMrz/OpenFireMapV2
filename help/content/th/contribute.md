## ก่อนเริ่ม {#vorher}

OpenFireMap แสดงข้อมูลจาก [OpenStreetMap](https://www.openstreetmap.org/) (OSM) คุณจึงแก้ไขใน OpenStreetMap ไม่ใช่ OpenFireMap และต้องมีบัญชี:

:::steps
1. ที่ [openstreetmap.org](https://www.openstreetmap.org/user/new) เลือก **Sign Up**
2. ตั้งชื่อผู้ใช้ อีเมล และรหัสผ่าน จากนั้นยืนยันอีเมล
3. ใช้บัญชีนี้เข้าสู่เครื่องมือด้านล่าง
:::

:::warn กฎสามข้อ
- **เพิ่มเฉพาะสิ่งที่เห็นด้วยตนเอง ณ สถานที่จริง** ตรวจตำแหน่งและชนิดที่หัวจ่ายน้ำ
- **อย่าคัดลอกข้อมูลจากแผนของผู้อื่น** แผนจากหน่วยงานประปาหรือเทศบาลมีลิขสิทธิ์ ใช้ได้เมื่อได้รับอนุญาตชัดเจนเท่านั้น
- **เขียนสรุปสั้น ๆ เมื่อบันทึก** เช่น “เพิ่มหัวจ่ายน้ำบนถนนสายหลัก”
:::

หน่วยดับเพลิงในเยอรมนีมีคู่มือสำรวจหัวจ่ายน้ำในพื้นที่ระหว่างการฝึกหรือเดินตรวจเมือง เฉพาะภาษาเยอรมัน: [Für Feuerwehren](/help/fire-brigades/)

## เลือกเครื่องมือ {#werkzeug}

| สถานการณ์ | เครื่องมือ | เหตุผล |
|---|---|---|
| อยู่หน้างาน ใช้โทรศัพท์ และต้องการเพิ่มหัวจ่ายน้ำอย่างรวดเร็ว | **Hydrantenjäger** | ออกแบบมาสำหรับหัวจ่ายน้ำ วางจุดด้วยเข็มทิศ และมีช่องกรอกน้อย |
| เดินทางและอยากเพิ่มข้อมูลระหว่างทาง | **StreetComplete** หรือ **Every Door** | ตอบคำถามเกี่ยวกับวัตถุใกล้เคียง |
| ใช้คอมพิวเตอร์แก้ไขตำแหน่งเฉพาะ | **โปรแกรมแก้ไข iD** | ทำงานในเบราว์เซอร์ที่ openstreetmap.org ไม่ต้องติดตั้ง |
| มีประสบการณ์และแก้ไขหลายจุด | **JOSM** (คอมพิวเตอร์) หรือ **Vespucci** (Android) | ควบคุมแท็กทั้งหมดได้ |

## ใช้ Hydrantenjäger {#hydrantenjaeger}

[Hydrantenjäger](https://hydrantenjaeger.de/) เป็นเว็บแอปสำหรับโทรศัพท์ซึ่งทำขึ้นเพื่องานนี้:

:::steps
1. เข้าสู่ระบบด้วยบัญชี OpenStreetMap
2. ยืนห่างหัวจ่ายน้ำประมาณสามเมตรแล้วหันโทรศัพท์ไปทางนั้น แอปวางจุดโดยใช้ GPS และเข็มทิศ
3. เลือกชนิดและตำแหน่ง กรอกเส้นผ่านศูนย์กลางและหมายเลขเฉพาะเมื่อแน่ใจ
4. อัปโหลด เสร็จแล้ว
:::

คู่มือชนิดหัวจ่ายน้ำโดยละเอียดอยู่ที่ [หน้าช่วยเหลือ Hydrantenjäger](https://hydrantenjaeger.de/help/)

## ใช้ StreetComplete หรือ Every Door {#apps}

- **[StreetComplete](https://streetcomplete.app/)** (Android, iOS) ถามเกี่ยวกับวัตถุใกล้เคียง เช่น “หัวจ่ายน้ำนี้เป็นชนิดใด” แล้วตอบด้วยการแตะ แอปเหมาะสำหรับเติมข้อมูลของวัตถุที่มีอยู่แล้ว
- **[Every Door](https://every-door.app/)** (Android, iOS) เหมาะกับการเพิ่มจุดใหม่ กดปุ่มบวก วางจุด เลือก “Fire Hydrant” แล้วกรอกข้อมูล

## ใช้โปรแกรมแก้ไข iD ในเบราว์เซอร์ {#id}

iD เป็นโปรแกรมแก้ไขมาตรฐานบน openstreetmap.org

:::steps
1. เปิด [openstreetmap.org](https://www.openstreetmap.org/) เข้าสู่ระบบ แล้วซูมไปยังหัวจ่ายน้ำ
2. คลิก **Edit** ด้านบน หากเป็นครั้งแรก ให้ทำตามบทแนะนำสั้น ๆ
3. คลิก **Point** แล้ววางจุดตรงตำแหน่งหัวจ่าย ภาพถ่ายทางอากาศช่วยกำหนดตำแหน่ง
4. พิมพ์ “hydrant” ในช่องค้นหาด้านซ้าย แล้วเลือกชุด **Fire Hydrant**
5. กรอก **Type** (ใต้ดิน แบบเสา ติดผนัง แบบท่อ), **Position** (เช่น ทางเท้าหรือช่องทาง), **Diameter** และ **Reference** หากทราบ
6. คลิก **Save** ด้านขวาบน ใส่คำอธิบายสั้น ๆ แล้วคลิก **Upload**
:::

:::tip แก้หัวจ่ายที่มีอยู่
คลิกหัวจ่าย แก้ข้อมูลด้านซ้าย แล้วบันทึก หากตำแหน่งผิด ให้ลากไปยังตำแหน่งที่ถูกต้อง ลบเฉพาะเมื่อยืนยันจากสถานที่จริงว่าไม่มีแล้ว
:::

## ใช้ JOSM หรือ Vespucci {#josm}

[JOSM](https://josm.openstreetmap.de/) เป็นโปรแกรมคอมพิวเตอร์ที่ใช้ Java ส่วน [Vespucci](https://vespucci.io/) เป็นโปรแกรมสำหรับ Android ทั้งสองแสดงแท็กทั้งหมด เหมาะกับงานจำนวนมาก เช่น อัปเดตหัวจ่ายในพื้นที่หลังเดินสำรวจ รายการแท็กอยู่ด้านล่าง

## แท็กสำคัญ {#tags}

OpenStreetMap อธิบายวัตถุด้วยแท็กในรูปแบบ `key=value` ชุดข้อมูลในแอปจะกำหนดค่าให้ หากกรอกเองให้ใช้:

| วัตถุ | แท็ก | ความหมาย |
|---|---|---|
| หัวจ่ายน้ำ | `emergency=fire_hydrant` | ต้องมีในหัวจ่ายทุกจุด |
| | `fire_hydrant:type=underground` | หัวจ่ายใต้ดิน (รวม `pillar`, `wall`, `pipe`) |
| | `fire_hydrant:diameter=80` | ขนาดระบุ DN ตามป้าย |
| | `fire_hydrant:position=sidewalk` | ตำแหน่ง (รวม `lane`, `parking_lot`, `green`) |
| | `ref=123` | หมายเลขหัวจ่าย หากมี |
| | `fire_hydrant:pressure=4` | แรงดันเป็นบาร์ หากทราบ |
| จุดดูดน้ำ | `emergency=suction_point` | จุดสูบน้ำจากแหล่งน้ำ |
| ถังน้ำ | `emergency=water_tank` | ถังหรือแท็งก์น้ำดับเพลิง |
| สระน้ำดับเพลิง | `emergency=fire_water_pond` | สระที่ใช้เป็นแหล่งน้ำดับเพลิง |
| เครื่องกระตุกหัวใจ | `emergency=defibrillator` | และ `indoor=yes/no`, `defibrillator:location=…`, `opening_hours=…` |
| สถานีดับเพลิง | `amenity=fire_station` | อาคารหรือพื้นที่หน่วยดับเพลิง |

หน้า [สัญลักษณ์แผนที่](/symbols/) แสดงแท็กบน OpenFireMap และ [วิกิ OpenStreetMap](https://wiki.openstreetmap.org/wiki/Tag:emergency%3Dfire_hydrant) อธิบายเพิ่มเติม

## การเปลี่ยนแปลงจะแสดงเมื่อใด {#anzeige}

หลังอัปโหลด หัวจ่ายน้ำจะบันทึกใน OpenStreetMap ทันที และจะแสดงใน OpenFireMap เมื่อบริการที่แผนที่ใช้ประมวลผลข้อมูลแล้ว โดยมากไม่นานแต่ไม่มีเวลาตายตัว ดูสาเหตุที่ล่าช้าใน [ข้อมูลและความใหม่](../data/#verzoegerung)
