## แผนที่พื้นหลัง {#hintergrund}

:::figure layers frame=plain
เมนู “Map layers” บนคอมพิวเตอร์
:::

| พื้นหลัง | เหมาะสำหรับ |
|---|---|
| **Standard (Voyager)** | ใช้ทั่วไป: ถนนชัดเจน มีเลขบ้านตั้งแต่ซูม 17 |
| **Print (Light)** | พิมพ์และส่งออก: พื้นหลังสว่าง สัญลักษณ์โดดเด่น |
| **Night (Dark)** | กลางคืนและในรถ ลดแสงจ้า |
| **Satellite (Esri)** | สำรวจพื้นที่: อาคาร ทางเข้ารถ และพืชพรรณ |
| **Topographic (OSM)** | ภูมิประเทศพร้อมเส้นชั้นความสูง ทางเดิน และแหล่งน้ำ |
| **OSM (Intl)** | รูปแบบ OpenStreetMap ที่คุ้นเคย |
| **OSM (DE Style)** | OpenStreetMap ในรูปแบบเยอรมัน |
| **Bavaria Base** | แผนที่ทางการของหน่วยงานสำรวจบาวาเรีย เฉพาะในบาวาเรีย |
| **Bavaria Aerial** | ภาพถ่ายทางอากาศทางการ เฉพาะในบาวาเรีย |

พื้นหลังที่เลือกจะอยู่ในลิงก์แชร์และใช้กับ [การส่งออก](../export/) ด้วย

:::tip หาเลขบ้าน
ที่ระดับซูม 17 และ 18 แผนที่ Standard และ OSM แสดงเลขบ้าน ช่วยจับคู่หัวจ่ายน้ำกับที่อยู่ได้ง่าย
:::

## ระดับซูม {#zoom}

OpenFireMap โหลดเฉพาะข้อมูลที่เหมาะกับมุมมอง ระดับซูมแสดงอยู่ในกล่องสถานะ

| ระดับซูม | สิ่งที่แสดง |
|---|---|
| ต่ำกว่า 12 | ยังไม่มีวัตถุ (สถานะ “Standby”) |
| 12–13 | สถานีดับเพลิงเป็นจุด |
| ตั้งแต่ 14 | สถานีเป็นสัญลักษณ์และเขตเทศบาล |
| 15–16 | หัวจ่ายน้ำ จุดน้ำ และเครื่องกระตุกหัวใจเป็นจุดสี |
| ตั้งแต่ 16 | วงกลม 100 เมตรเมื่อแตะหัวจ่ายน้ำ |
| ตั้งแต่ 17 | สัญลักษณ์พร้อมตัวอักษร ใช้แป้นพิมพ์เลือกได้ |
| 18 | รายละเอียดเมื่อชี้เมาส์ |

## สีและสัญลักษณ์ {#symbole}

สีบอกประเภทสิ่งของ ส่วนตัวอักษรบอกชนิด:

- **สีแดง:** หัวจ่ายน้ำ **U** คือหัวจ่ายใต้ดิน **O** คือหัวจ่ายแบบเสา **Ø** คือหัวจ่ายแบบแห้ง ชนิดติดผนังและชนิดอื่นมีเครื่องหมายเฉพาะ
- **สีน้ำเงิน:** จุดน้ำ เช่น สระน้ำดับเพลิง ถังเก็บน้ำ บ่อน้ำดับเพลิง หรือจุดดูดน้ำ
- **สีเขียว:** เครื่องกระตุกหัวใจ (AED)
- **สถานีดับเพลิง** ใช้สัญลักษณ์อาคารเฉพาะ

ตั้งแต่ระดับซูม 17 วัตถุหลายรายการที่อยู่ห่างกันไม่เกิน 5 เมตรจะถูกรวมกลุ่มพร้อมแสดงจำนวน

หน้า **[สัญลักษณ์แผนที่](/symbols/)** แสดงสัญลักษณ์และแท็ก OpenStreetMap แต่ละรายการ เหมาะสำหรับผู้ทำแผนที่ที่ต้องการรู้ว่าสัญลักษณ์มาจากแท็กใด

:::note ที่มาของรายละเอียด
ชนิด เส้นผ่านศูนย์กลาง หมายเลข และข้อมูลอื่นมาจาก OpenStreetMap หากไม่ได้ระบุชนิดหัวจ่าย แผนที่จะแสดงจุดสีแดงไม่มีตัวอักษร ดูวิธีเพิ่มได้ที่ [ร่วมแก้ไข](../contribute/)
:::
