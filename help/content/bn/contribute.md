## শুরু করার আগে {#vorher}

OpenFireMap [OpenStreetMap](https://www.openstreetmap.org/) (OSM)-এর ডেটা দেখায়। তাই OpenFireMap-এ সম্পাদনা নয়, OpenStreetMap-এ করতে হবে। আপনার অ্যাকাউন্ট দরকার:

:::steps
1. [openstreetmap.org](https://www.openstreetmap.org/user/new)-এ **Sign Up** বেছে নিন।
2. ব্যবহারকারীর নাম, ই-মেইল ঠিকানা ও পাসওয়ার্ড দিন, তারপর ই-মেইল নিশ্চিত করুন।
3. নিচের সব সরঞ্জামে লগ ইন করতে এই অ্যাকাউন্ট ব্যবহার করুন।
:::

:::warn তিনটি নিয়ম
- **সাইটে নিজে যা দেখেছেন শুধু তা যোগ করুন।** হাইড্র্যান্টের কাছে ধরন ও অবস্থান যাচাই করুন।
- **অন্যের পরিকল্পনা থেকে ডেটা কপি করবেন না।** পানি সরবরাহ প্রতিষ্ঠান বা পৌরসভার হাইড্র্যান্ট পরিকল্পনা কপিরাইটে সুরক্ষিত। স্পষ্ট অনুমতি ছাড়া ব্যবহার করবেন না।
- **সংরক্ষণের সময় কী বদলেছেন সংক্ষেপে লিখুন,** যেমন “Added hydrants on Main Street”।
:::

## কোন সরঞ্জামটি আপনার জন্য? {#werkzeug}

| আপনি … | ব্যবহার করুন | কেন |
|---|---|---|
| ফোন নিয়ে সাইটে আছেন ও দ্রুত হাইড্র্যান্ট যোগ করতে চান | **Hydrantenjäger** | হাইড্র্যান্টের জন্য তৈরি, কম্পাসে বিন্দু বসায়, অল্প কয়েকটি ঘর |
| পথে পথে জিনিস যোগ করতে চান | **StreetComplete** বা **Every Door** | কাছাকাছি বস্তু নিয়ে প্রশ্নের উত্তর দিন, হাইড্র্যান্টসহ |
| কম্পিউটারে নির্দিষ্ট স্থানে কাজ করতে চান | **iD editor** | openstreetmap.org-এ ব্রাউজারে চলে, ইনস্টল দরকার নেই |
| অভিজ্ঞ এবং একসঙ্গে অনেক হাইড্র্যান্ট সম্পাদনা করতে চান | **JOSM** (কম্পিউটার) বা **Vespucci** (Android) | সব ট্যাগে পূর্ণ নিয়ন্ত্রণ |

## Hydrantenjäger দিয়ে {#hydrantenjaeger}

[Hydrantenjäger](https://hydrantenjaeger.de/) ফোনের জন্য একটি ওয়েব অ্যাপ, এই কাজটির জন্যই তৈরি:

:::steps
1. OpenStreetMap অ্যাকাউন্টে লগ ইন করুন।
2. হাইড্র্যান্টের সামনে প্রায় তিন মিটার দূরে দাঁড়িয়ে ফোনটি তার দিকে তাক করুন। GPS ও কম্পাস ব্যবহার করে অ্যাপ সেখানে বিন্দু বসায়।
3. ধরন ও অবস্থান বেছে নিন; নিশ্চিত না হলে ব্যাস ও নম্বর দেবেন না।
4. আপলোড করুন। হয়ে গেল।
:::

সব ধরনের হাইড্র্যান্টসহ বিস্তারিত নির্দেশিকা [Hydrantenjäger সহায়তা পৃষ্ঠায়](https://hydrantenjaeger.de/help/) আছে।

## StreetComplete বা Every Door দিয়ে {#apps}

- **[StreetComplete](https://streetcomplete.app/)** (Android, iOS) কাছাকাছি বস্তু নিয়ে প্রশ্ন দেখায়, যেমন “এই ফায়ার হাইড্র্যান্টের ধরন কী?” ট্যাপ করে উত্তর দিন। অ্যাপটি মূলত বিদ্যমান বস্তুর অনুপস্থিত বিবরণ পূরণে কাজে লাগে।
- **[Every Door](https://every-door.app/)** (Android, iOS) বিন্দু যোগ করার জন্য তৈরি। প্লাস বোতামে নতুন বিন্দু বসিয়ে “Fire Hydrant” বেছে ঘরগুলো পূরণ করুন।

## ব্রাউজারে iD এডিটর দিয়ে {#id}

iD এডিটর হলো openstreetmap.org-এর ডিফল্ট এডিটর।

:::steps
1. [openstreetmap.org](https://www.openstreetmap.org/) খুলে লগ ইন করুন এবং হাইড্র্যান্টের এলাকায় জুম করুন।
2. ওপরে **Edit** ক্লিক করুন। প্রথমবার একটি ছোট পরিচিতিমূলক নির্দেশিকা আসে; এটি অনুসরণ করা ভালো।
3. ওপরে **Point** ক্লিক করে হাইড্র্যান্ট যেখানে আছে ঠিক সেখানে বিন্দু বসান। অবস্থান বুঝতে আকাশচিত্র সাহায্য করে।
4. বাঁদিকের অনুসন্ধান ঘরে “hydrant” লিখে **Fire Hydrant** প্রিসেট বেছে নিন।
5. ঘরগুলো পূরণ করুন: **Type** (ভূগর্ভস্থ, স্তম্ভ, দেয়াল, পাইপ), **Position** (যেমন ফুটপাত বা লেন), এবং জানা থাকলে **Diameter** ও **Reference**।
6. ওপরের ডানদিকে **Save** ক্লিক করে সংক্ষিপ্ত মন্তব্য লিখুন এবং **Upload** ক্লিক করুন।
:::

:::tip বিদ্যমান হাইড্র্যান্ট ঠিক করা
বিদ্যমান হাইড্র্যান্টে ক্লিক করে বাঁদিকে ঘরগুলো বদলে একইভাবে সংরক্ষণ করুন। অবস্থান ভুল হলে সঠিক জায়গায় টেনে নিন। সাইটে নিশ্চিত না হয়ে এটি মুছবেন না।
:::

## JOSM বা Vespucci দিয়ে {#josm}

[JOSM](https://josm.openstreetmap.de/) কম্পিউটারের (Java) এডিটর, [Vespucci](https://vespucci.io/) Android-এর বিকল্প। দুটোতেই সব ট্যাগ সরাসরি দেখা যায় এবং বড় কাজে উপযোগী, যেমন এলাকায় ঘুরে এসে ফায়ার ব্রিগেডের সব হাইড্র্যান্ট আপডেট করা। ট্যাগগুলোর তালিকা নিচে আছে।

## গুরুত্বপূর্ণ ট্যাগ {#tags}

OpenStreetMap প্রতিটি বস্তুকে `key=value` আকারের ট্যাগ দিয়ে বর্ণনা করে। অ্যাপের প্রিসেট এগুলো সেট করে দেয়। নিজে লিখলে ব্যবহার করুন:

| বস্তু | ট্যাগ | অর্থ |
|---|---|---|
| হাইড্র্যান্ট | `emergency=fire_hydrant` | প্রতিটি হাইড্র্যান্টে আবশ্যক |
| | `fire_hydrant:type=underground` | ভূগর্ভস্থ হাইড্র্যান্ট (এছাড়া `pillar`, `wall`, `pipe`) |
| | `fire_hydrant:diameter=80` | সাইন অনুযায়ী নামমাত্র ব্যাস, মিমিতে |
| | `fire_hydrant:position=sidewalk` | অবস্থান (এছাড়া `lane`, `parking_lot`, `green`) |
| | `ref=123` | থাকলে হাইড্র্যান্টের নম্বর |
| | `fire_hydrant:pressure=4` | চাপ, বারে; জানা থাকলেই দিন |
| পানি টানার স্থান | `emergency=suction_point` | জলাশয় থেকে পানি তোলার স্থান |
| পানির ট্যাংক | `emergency=water_tank` | জলাধার বা অগ্নিনির্বাপণের ট্যাংক |
| ফায়ার ওয়াটার পুকুর | `emergency=fire_water_pond` | অগ্নিনির্বাপণের পানির উৎস হিসেবে ব্যবহৃত পুকুর |
| ডিফিব্রিলেটর | `emergency=defibrillator` | সঙ্গে `indoor=yes/no`, `defibrillator:location=…`, `opening_hours=…` |
| ফায়ার স্টেশন | `amenity=fire_station` | ফায়ার সার্ভিসের ভবন বা সাইট |

OpenFireMap-এ ট্যাগগুলো কেমন দেখায় তা [মানচিত্রের প্রতীক](/symbols/) পৃষ্ঠায় আছে। [OpenStreetMap wiki](https://wiki.openstreetmap.org/wiki/Tag:emergency%3Dfire_hydrant)-তে বিস্তারিত বর্ণনা রয়েছে।

## পরিবর্তন কখন দেখা যাবে? {#anzeige}

আপলোডের পর হাইড্র্যান্ট সঙ্গে সঙ্গে OpenStreetMap-এ সংরক্ষিত হয়। মানচিত্র যে পরিষেবাগুলো থেকে ডেটা আনে সেগুলো পরিবর্তন প্রক্রিয়া করলে OpenFireMap-এ দেখা যায়। সাধারণত দ্রুত হয়, তবে নির্দিষ্ট সময় নেই। কী কারণে দেরি হতে পারে তা [ডেটা ও হালনাগাদ](../data/#verzoegerung) অংশে ব্যাখ্যা করা হয়েছে।
