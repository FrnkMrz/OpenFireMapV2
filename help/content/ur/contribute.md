## شروع کرنے سے پہلے {#vorher}

OpenFireMap، [OpenStreetMap](https://www.openstreetmap.org/) (OSM) کا ڈیٹا دکھاتا ہے۔ ترمیم OpenStreetMap میں کریں، OpenFireMap میں نہیں۔ اکاؤنٹ درکار ہے:

:::steps
1. [openstreetmap.org](https://www.openstreetmap.org/user/new) پر **Sign Up** منتخب کریں۔
2. صارف نام، ای میل اور پاس ورڈ منتخب کرکے ای میل کی تصدیق کریں۔
3. نیچے دیے گئے ٹولز میں اسی اکاؤنٹ سے لاگ ان کریں۔
:::

:::warn تین اصول
- **صرف وہی شامل کریں جو آپ نے موقع پر دیکھا ہو۔** ہائیڈرنٹ کی جگہ اور قسم جانچیں۔
- **دوسروں کے پلان سے ڈیٹا نقل نہ کریں۔** واٹر یوٹیلیٹی یا بلدیہ کے ہائیڈرنٹ پلان کاپی رائٹ کے تحت ہیں؛ واضح اجازت کے بغیر استعمال نہ کریں۔
- **محفوظ کرتے وقت مختصراً تبدیلی بتائیں،** مثلاً “مین اسٹریٹ پر ہائیڈرنٹس شامل کیے”۔
:::

جرمنی کی فائر بریگیڈز مشق یا شہر کے دورے میں اپنے علاقے کے ہائیڈرنٹس جانچنے کی رہنمائی دیکھ سکتی ہیں؛ یہ صرف جرمن میں ہے: [Für Feuerwehren](/help/fire-brigades/)۔

## کون سا ٹول مناسب ہے؟ {#werkzeug}

| صورتِ حال | ٹول | وجہ |
|---|---|---|
| فون کے ساتھ موقع پر جلد ہائیڈرنٹ شامل کرنا | **Hydrantenjäger** | ہائیڈرنٹس کے لیے بنایا گیا، قطب نما سے پوائنٹ لگاتا، کم خانے |
| چلتے پھرتے چیزیں شامل کرنا | **StreetComplete** یا **Every Door** | قریب کی چیزوں کے سوالات کے جواب |
| کمپیوٹر پر خاص جگہیں ترمیم کرنا | **iD ایڈیٹر** | openstreetmap.org پر براؤزر میں چلتا، تنصیب نہیں |
| تجربہ کار، کئی ہائیڈرنٹس ایک ساتھ | **JOSM** (کمپیوٹر) یا **Vespucci** (Android) | تمام ٹیگز پر مکمل اختیار |

## Hydrantenjäger کے ساتھ {#hydrantenjaeger}

[Hydrantenjäger](https://hydrantenjaeger.de/) فون کے لیے ویب ایپ ہے جو اسی کام کے لیے بنائی گئی ہے:

:::steps
1. اپنے OpenStreetMap اکاؤنٹ سے لاگ اِن کریں۔
2. ہائیڈرنٹ سے تقریباً تین میٹر سامنے کھڑے ہوکر فون اس کی طرف کریں۔ ایپ GPS اور قطب نما سے پوائنٹ لگاتی ہے۔
3. قسم اور جگہ منتخب کریں؛ قطر اور نمبر صرف یقین ہونے پر درج کریں۔
4. اپ لوڈ کریں۔ مکمل۔
:::

ہائیڈرنٹ اقسام کی تفصیلی رہنمائی [Hydrantenjäger مدد صفحے](https://hydrantenjaeger.de/help/) پر ہے۔

## StreetComplete یا Every Door کے ساتھ {#apps}

- **[StreetComplete](https://streetcomplete.app/)** (Android، iOS) قریب کی چیزوں کے بارے میں سوال کرتا ہے، مثلاً “یہ کون سی قسم کا فائر ہائیڈرنٹ ہے؟” ٹیپ کرکے جواب دیں۔ یہ موجودہ آبجیکٹس کی کمی پوری کرنے کے لیے بنایا گیا ہے۔
- **[Every Door](https://every-door.app/)** (Android، iOS) نئے پوائنٹس شامل کرتا ہے۔ پلس بٹن سے پوائنٹ رکھیں، “Fire Hydrant” منتخب کریں اور خانے پُر کریں۔

## براؤزر میں iD ایڈیٹر {#id}

iD، openstreetmap.org کا معیاری ایڈیٹر ہے۔

:::steps
1. [openstreetmap.org](https://www.openstreetmap.org/) کھولیں، لاگ ان کریں اور ہائیڈرنٹ کے مقام پر زوم کریں۔
2. اوپر **Edit** دبائیں۔ پہلی بار مختصر تعارف دیکھیں۔
3. **Point** دباکر ہائیڈرنٹ کی بالکل درست جگہ پر پوائنٹ رکھیں۔ فضائی تصویر سمت شناسی میں مدد دیتی ہے۔
4. بائیں تلاش میں “hydrant” لکھیں اور **Fire Hydrant** پری سیٹ منتخب کریں۔
5. **Type** (زیرِ زمین، ستون، دیوار، پائپ)، **Position** (مثلاً فٹ پاتھ یا لین)، **Diameter** اور معلوم ہو تو **Reference** پُر کریں۔
6. اوپر دائیں **Save** دبائیں، مختصر تبصرہ لکھیں اور **Upload** منتخب کریں۔
:::

:::tip موجودہ ہائیڈرنٹ درست کریں
موجودہ ہائیڈرنٹ پر کلک کریں، بائیں جانب معلومات بدلیں اور محفوظ کریں۔ جگہ غلط ہو تو پوائنٹ درست جگہ کھینچیں۔ حذف صرف تب کریں جب موقع پر یقین ہو کہ ہائیڈرنٹ موجود نہیں۔
:::

## JOSM یا Vespucci کے ساتھ {#josm}

[JOSM](https://josm.openstreetmap.de/) کمپیوٹر کا Java ایڈیٹر ہے، [Vespucci](https://vespucci.io/) Android کے لیے۔ دونوں تمام ٹیگز دکھاتے اور بڑے کام، مثلاً سروے کے بعد پورے علاقے کے ہائیڈرنٹس اپ ڈیٹ کرنے، کے لیے موزوں ہیں۔

## اہم ٹیگز {#tags}

OpenStreetMap آبجیکٹس کو `key=value` ٹیگز سے بیان کرتا ہے۔ ایپس کے پری سیٹس یہ خود بھرتے ہیں۔ خود درج کریں تو:

| آبجیکٹ | ٹیگ | معنی |
|---|---|---|
| ہائیڈرنٹ | `emergency=fire_hydrant` | ہر ہائیڈرنٹ کے لیے لازمی |
| | `fire_hydrant:type=underground` | زیرِ زمین (یا `pillar`, `wall`, `pipe`) |
| | `fire_hydrant:diameter=80` | برائے نام قطر DN، نشان کے مطابق |
| | `fire_hydrant:position=sidewalk` | جگہ (یا `lane`, `parking_lot`, `green`) |
| | `ref=123` | ہائیڈرنٹ نمبر، اگر ہو |
| | `fire_hydrant:pressure=4` | دباؤ بار میں، معلوم ہو تو |
| سکشن پوائنٹ | `emergency=suction_point` | آبی ذخیرے سے پانی لینے کی جگہ |
| پانی کا ٹینک | `emergency=water_tank` | حوض یا فائر واٹر ٹینک |
| فائر واٹر تالاب | `emergency=fire_water_pond` | آگ بجھانے کے لیے استعمال ہونے والا تالاب |
| ڈیفبریلیٹر | `emergency=defibrillator` | ساتھ `indoor=yes/no`, `defibrillator:location=…`, `opening_hours=…` |
| فائر اسٹیشن | `amenity=fire_station` | فائر سروس کی عمارت یا جگہ |

[نقشے کی علامات](/symbols/) دکھاتا ہے کہ ٹیگز OpenFireMap میں کیسے نظر آتے ہیں۔ تفصیل [OpenStreetMap وکی](https://wiki.openstreetmap.org/wiki/Tag:emergency%3Dfire_hydrant) میں ہے۔

## تبدیلی کب دکھے گی؟ {#anzeige}

اپ لوڈ کے بعد ہائیڈرنٹ فوراً OpenStreetMap میں محفوظ ہوتا ہے۔ OpenFireMap میں تب دکھتا ہے جب نقشہ کے ڈیٹا ذرائع تبدیلی پر عمل کر لیں۔ عموماً جلد، مگر وقت مقرر نہیں۔ ممکنہ تاخیر [ڈیٹا اور تازگی](../data/#verzoegerung) میں بیان ہے۔
