## 데이터 출처 {#quelle}

소화전, 급수 지점, 소방서와 자동심장충격기는 [OpenStreetMap](https://www.openstreetmap.org/) 커뮤니티가 추가합니다. 지역 소방대원이 참여하는 경우도 많습니다. OpenFireMap은 데이터를 표시할 뿐 수정하지 않습니다.

## OpenFireMap의 소화전 불러오기 방식 {#ladeweg}

지역에 따라 두 가지 방법을 사용합니다.

- **준비된 타일:** 독일, 오스트리아, 스위스, 리히텐슈타인, 룩셈부르크와 유럽의 다른 40개국은 OpenStreetMap 국가 추출본(Geofabrik)에서 데이터 타일을 미리 만듭니다. Cloudflare에 저장하고 캐시를 통해 전달합니다. 브라우저는 현재 보기에 필요한 몇 개의 타일만 가져옵니다.
- **Overpass API:** 그 밖의 지역에서는 보이는 영역과 주변 범위를 공개 Overpass 서버에 직접 요청합니다.

:::note 독일과 유럽에서 더 빠른 이유
Overpass가 더 빨리 응답해서가 아닙니다. 이들 국가에서는 소화전 데이터에 Overpass 질의를 할 필요 없이 준비된 타일을 읽습니다. Overpass에는 기준 데이터 날짜 이후의 변경 사항만 요청하므로 질의가 훨씬 작습니다.
:::

### Overpass API란? {#overpass}

[Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API)는 “이 사각형 안의 모든 소화전”처럼 유형과 영역별로 OpenStreetMap 데이터를 조회하는 공개 서비스입니다. 자원봉사자와 단체가 서버를 운영하며 여러 앱이 함께 사용합니다.

응답 속도는 다음에 따라 달라집니다.

- OpenFireMap이 사용하는 서버의 **부하**
- 영역의 **크기**와 질의 실행 시간
- 서버가 과부하되거나 요청을 제한할 때의 **대기 및 거부**

OpenFireMap은 네 개의 Overpass 서버를 알고 있으며 무작위 순서로 시도합니다. 응답이 없거나 과부하를 보고하면 잠시 기다렸다가 다음 서버를 요청합니다. 불러온 영역은 브라우저 로컬 캐시에 보관합니다.

## 데이터 최신성 {#aktualitaet}

| 지역 | 기준 데이터 | 새 항목 및 변경 항목 |
|---|---|---|
| 독일, 오스트리아, 스위스, 리히텐슈타인, 룩셈부르크 | 준비된 타일, 보통 매일 재생성 | Overpass에서 요청 |
| 유럽의 다른 40개국 | 준비된 타일, 보통 매주 재생성 | 기준 데이터가 10일 이내일 때 Overpass에서 요청 |
| 나머지 세계 | Overpass 서버의 데이터 | 매 질의 때 요청 |

준비된 타일을 불러온 뒤 OpenFireMap은 기준 날짜 이후 현재 보기에서 바뀐 데이터를 백그라운드로 요청해 지도에 추가합니다.

### 새 항목이 바로 나타나지 않는 이유 {#verzoegerung}

OpenStreetMap의 변경이 OpenFireMap에 즉시 나타나지는 않습니다.

- **처리:** Overpass 서버가 변경 사항을 받아야 합니다. 데이터가 너무 오래되었다고 판단하면 OpenFireMap은 응답을 버리고 기준 데이터를 보여 줍니다.
- **캐시:** 영역별 질의 결과를 몇 분간 보관하고, 이미 불러온 영역은 로컬 캐시에도 저장합니다.
- **서비스 중단:** Overpass가 과부하되거나 연결되지 않으면 다음 요청이 성공할 때까지 기준 데이터가 유지됩니다. OpenFireMap이 이를 제어할 수는 없습니다.

따라서 일정한 시간을 약속할 수 없습니다. 아직 항목이 보이지 않으면 잠시 후 지도를 다시 불러오세요.

:::note 삭제된 객체
업데이트는 새 객체와 변경된 객체만 찾습니다. OpenStreetMap에서 삭제된 소화전은 준비된 타일의 다음 기준 데이터 업데이트 때 사라집니다.
:::

## “데이터 상태 및 출처” 창 {#popover}

:::figure data frame=plain
데이터 상태 및 출처: 기준 데이터는 어제 자료이며 이때 실시간 업데이트에 연결할 수 없었습니다.
:::

컴퓨터에서는 상태 상자의 “데이터 상태 세부 정보”를 선택하고, 스마트폰에서는 상태 상자를 탭합니다.

- **출처:** 준비된 타일(DACHLiLu 또는 유럽), 실시간 질의 또는 로컬 캐시.
- **기준 데이터 날짜:** 국가 추출본이 생성된 시점. 여러 국가가 보이면 가장 오래된 날짜를 표시합니다.
- **실시간 업데이트:** 최신 변경 사항을 불러왔는지 표시합니다. “사용할 수 없음”은 실시간 서비스에 연결되지 않아 기준 데이터가 보인다는 뜻입니다. 화살표 버튼으로 다시 시도할 수 있습니다.

상태 상자에는 “기준: 1일 전 +Sync”처럼 간단히 표시됩니다.

## 상태 페이지 {#statusseite}

[상태 페이지](/status/)에서 국가별 OpenStreetMap 데이터의 경과 시간, 지도 마지막 갱신 시간, 주민당 소화전·소방서·자동심장충격기 수를 볼 수 있습니다. 독일어와 영어로 제공됩니다.

## 로컬 캐시 {#cache}

방문한 영역을 빠르게 표시하기 위해 OpenFireMap은 불러온 데이터를 브라우저에 저장합니다. “정보 및 법률”의 **로컬 캐시**에서 끔, 1시간, 1일, 3일, 7일(기본값), 30일 중 선택하세요.

데이터는 기기에 남습니다. 캐시는 업데이트를 대체하지 않습니다. 영역을 다시 열면 최신 데이터와 비교해 확인합니다.

## 인터넷 연결 없이 {#offline}

OpenFireMap은 오프라인 지도가 아닙니다. 캐시 영역은 잠시 볼 수 있지만 새 영역과 검색에는 연결이 필요합니다. 네트워크가 없는 현장에서는 인쇄한 [도시 안내도](../town-plan/)나 [내보낸 파일](../export/)이 더 적합합니다.

## 로딩이 오래 걸릴 때 {#laden}

준비된 국가 밖에서는 모든 데이터가 Overpass에서 옵니다. 서버가 바쁘면 OpenFireMap이 다음 서버를 시도하며 화면 아래에 진행 상황이 표시됩니다. 도움이 되지 않으면 확대해 질의를 줄이고 잠시 후 다시 시도하세요. 모든 서버가 과부하 상태면 Overpass 자체가 병목이므로 나중에 다시 불러와야 합니다.

:::warn 작전용 자료가 아닙니다
데이터 품질은 OpenStreetMap 기록에 달려 있습니다. 누락되거나 오래되었거나 잘못되었을 수 있으며 상황실이나 수도 사업자의 정보를 대체하지 않습니다. 긴급 상황에는 항상 긴급 전화번호(유럽에서는 112)로 연락하세요.
:::
