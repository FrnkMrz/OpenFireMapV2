## 목표 {#ziel}

지도는 **WCAG 2.2 AA 수준** 지침을 따릅니다. OpenFireMap을 변경할 때마다 키보드 조작, 화면 낭독기 이름, 색 대비, 400% 확대와 컨트롤 최소 크기를 자동 검사합니다. 이 도움말과 지도 기호 페이지도 같은 방식으로 검사합니다.

:::note 현재 상태를 솔직히 알립니다
자동 검사는 모든 문제를 찾지 못합니다. 실제 기기에서 화면 낭독기 테스트는 아직 남아 있습니다. 문제를 발견하면 아래 연락처로 알려 주세요. 모든 의견이 도움이 됩니다.
:::

## 키보드 사용 {#tastatur}

마우스로 가능한 모든 작업을 키보드로도 할 수 있습니다.

| 키 | 효과 |
|---|---|
| <kbd>Tab</kbd> | 다음 컨트롤로 이동. 첫 위치는 “지도 건너뛰기” |
| 화살표 키 | 지도가 포커스를 받았을 때 화면 이동 |
| <kbd>+</kbd>, <kbd>−</kbd> | 확대 및 축소 |
| 확대 단계 17부터 <kbd>Tab</kbd> | 지도 기호 사이 이동 |
| 기호에서 <kbd>Enter</kbd> 또는 <kbd>Space</kbd> | 세부 정보를 열고 소화전은 반경 100미터 원도 표시 |
| <kbd>Escape</kbd> | 세부 정보, 원, 메뉴와 대화상자 닫기; 내보내기 영역 선택 취소 |

포커스는 항상 명확하게 보입니다. 메뉴나 대화상자가 열리면 포커스가 안으로 이동해 닫을 때까지 유지된 뒤 연 버튼으로 돌아옵니다.

**마우스 없이 내보내기:** 내보내기 메뉴에서 **보이는 영역 사용**을 선택하면 사각형을 끌지 않고 현재 지도를 선택합니다. 자세한 내용은 [내보내기](../export/)를 참조하세요.

**마우스 없이 도시 안내도:** 도우미 3단계에서 <kbd>Tab</kbd>으로 제목, 범례와 상자를 선택하고 화살표 키로 움직입니다. <kbd>Shift</kbd>를 함께 누르면 더 큰 폭으로 이동합니다. <kbd>Alt</kbd> + 화살표 키로 지도의 크기를 바꿉니다. [도시 안내도](../town-plan/#schritt-3)를 참조하세요.

## 화면 낭독기 사용 {#screenreader}

- **지도:** 이름이 있는 영역으로 표시되며 키보드 사용법을 안내합니다.
- **기호:** 확대 단계 17부터 모든 기호에 이름이 있습니다(예: 종류와 번호가 있는 “소화전”). <kbd>Enter</kbd>로 세부 정보를 열면 낭독합니다.
- **메시지:** “링크 복사됨”이나 로딩 오류를 알립니다. 오류는 우선해서 읽습니다. 확대 단계와 데이터 날짜를 표시하는 상태 상자는 이동할 때마다 읽지 않도록 의도적으로 조용합니다.
- **언어:** 지도에 제공되는 모든 언어에 화면 낭독기 레이블이 있습니다. 이 도움말은 독일어와 영어로 제공됩니다.

:::tip 기호가 많을 때
확대 단계 17 미만에서는 점 하나하나에 키보드로 접근할 수 없습니다. 수백 개의 Tab 정지가 생기기 때문입니다. <kbd>+</kbd>로 확대해 기호가 나타나게 하세요.
:::

## 시각 및 확대 {#sehen}

- **대비:** 패널 텍스트는 최소 4.5:1, 큰 글자와 기호는 3:1의 대비율을 갖습니다. 패널은 지도 위에 반투명하게 표시되므로 밝고 어두운 배경 모두에서 확인합니다.
- **확대:** 브라우저 페이지를 최대 400%까지 확대할 수 있습니다. 그러면 좁은 메뉴 화면으로 바뀌며 모든 메뉴를 열고 스크롤할 수 있습니다.
- **색상만으로 구분하지 않음:** 소화전은 색뿐 아니라 기호 문자(U, O, Ø 등)로도 구분합니다.
- **배경:** 대비가 약하거나 눈부시면 **인쇄 (Light)** 또는 **야간 (Dark)**을 선택하세요. [레이어와 기호](../layers/)를 참조하세요.

## 동작 {#bewegung}

운영체제에서 **동작 줄이기**를 켜면 OpenFireMap 애니메이션을 사용하지 않습니다. 검색과 위치 찾기에서 지도가 날아가듯 이동하지 않고 바로 이동합니다. 이 도움말의 움직임도 표시하지 않습니다.

## 스마트폰에서 {#smartphone}

컨트롤은 최소 24 × 24픽셀입니다. 확대 단계 17부터 기호를 탭해 세부 정보를 엽니다. VoiceOver 또는 TalkBack에서는 왼쪽 위 메뉴를 통해 버튼에 접근합니다. [스마트폰에서 지도 사용](../phone/)에서 더 알아보세요.

## 아직 시험하지 않은 항목 {#offen}

- 기기에서 화면 낭독기(VoiceOver, TalkBack, NVDA) 전체 시험
- 위성 배경을 포함한 모든 배경 지도에서 기호 대비 확인
- 화면 낭독기로 도시 안내도 도우미 사용

## 접근성 문제를 발견했나요? {#melden}

작동하지 않은 내용과 기기, 브라우저 및 사용한 화면 낭독기를 **[info@openfiremap.org](mailto:info@openfiremap.org)**로 알려 주세요. 기술에 익숙하다면 [GitHub 이슈](https://github.com/FrnkMrz/OpenFireMapV2/issues)를 열어도 됩니다.
