## 개요 {#ueberblick}

:::figure desktop frame=browser spots=search,locate,layers,export,share,marker,status,legal
컴퓨터의 OpenFireMap: 확대 단계 17의 뉘른베르크 구시가지.
:::

1. **검색:** 장소나 주소를 찾습니다.
2. **내 위치:** 현재 위치로 이동합니다.
3. **지도 레이어:** 배경 지도를 바꿉니다.
4. **내보내기:** 소화전 안내도는 PNG 또는 PDF로, 지점은 GPX 또는 CSV로 내보냅니다.
5. **공유:** 현재 보기의 링크를 복사합니다.
6. **소화전:** 세부 정보를 보려면 마우스를 올리고 100미터 원을 보려면 클릭합니다.
7. **상태 상자:** 확대 단계와 데이터 날짜입니다.
8. **정보 및 법률:** 도움말, 지도 기호, 법적 고지, 개인정보 보호, 설정입니다.

## 장소 찾기 {#suche}

왼쪽 위 검색창에 장소, 거리 또는 주소를 입력한 뒤 <kbd>Enter</kbd>를 누르거나 돋보기를 클릭합니다. 지도가 첫 번째 결과로 이동하고 확대 단계 16으로 확대되어 소화전이 보입니다.

검색에는 OpenStreetMap 검색 서비스인 Nominatim을 사용합니다. 장소와 주소를 찾지만 개별 소화전은 찾지 않습니다.

## 내 위치 {#standort}

위치 버튼은 현재 위치를 표시하고 확대 단계 17로 이동합니다. 처음에는 브라우저가 OpenFireMap의 위치 사용을 허용할지 묻습니다. 위치는 브라우저 안에서만 사용하며 저장하지 않습니다.

:::tip 위치를 찾을 수 없나요?
브라우저에서 openfiremap.org의 위치 접근이 허용되어 있는지 확인하세요. GPS가 없는 컴퓨터에서는 위치가 수백 미터 정도 부정확할 수 있습니다.
:::

## 소화전 및 기타 객체 {#objekte}

확대 단계에 따라 표시되는 내용이 달라집니다.

| 확대 단계 | 표시 내용 |
|---|---|
| 12 미만 | 아직 객체 없음 |
| 12부터 | 소방서 |
| 14부터 | 소방서 기호와 시 경계 |
| 15부터 | 소화전, 급수 지점, 자동심장충격기가 색 점으로 표시 |
| 17부터 | 모든 객체가 문자 기호로 표시 |
| 18부터 | 마우스를 올리면 세부 정보 |

:::figure marker frame=plain
소화전을 클릭하면 반경 100미터 원이 표시됩니다.
:::

**세부 정보 보기:** 확대 단계 18부터 기호에 마우스를 올리면 정보가 열립니다. 키보드에서는 단계 17부터 가능합니다. <kbd>Tab</kbd>으로 기호를 선택하고 <kbd>Enter</kbd>를 누르세요.

**반경과 거리:** 단계 16부터 소화전을 클릭하면 반경 100미터의 점선 원이 나타납니다. 호스가 닿는 소화전을 가늠하는 데 도움이 됩니다. 단계 17부터 원에 “100 m”가 표시됩니다. 먼저 **내 위치**를 사용했다면 단계 17부터 현재 위치와 소화전 사이의 거리도 파란 선으로 표시됩니다.

세부 정보에는 OpenStreetMap에 기록된 종류, 지름, 번호, 압력, 위치, 운영자 등이 나옵니다. 정보가 빠져 있다면 아직 누군가 추가하지 않은 것입니다. [기여하기](../contribute/)에서 추가 방법을 확인하세요.

[레이어와 기호](../layers/) 페이지에서 기호와 색상을 설명합니다.

## 지도 레이어 {#ebenen}

지도 아이콘으로 배경 지도(일반, 인쇄, 야간, 위성, 지형, OSM 스타일 두 가지, 바이에른의 BayernAtlas와 항공 사진)를 선택합니다. 소방 객체는 항상 위에 표시됩니다. [레이어와 기호](../layers/)에서 용도에 맞는 배경을 확인하세요.

## 공유 및 링크 {#teilen}

공유 버튼은 현재 보기를 그대로 여는 링크를 클립보드에 복사합니다. 링크를 연 사람은 같은 장소, 확대 단계와 배경을 보게 됩니다.

지도를 움직이면 브라우저 주소도 바뀝니다. 형식은 `#zoom/latitude/longitude/background`입니다. 예: `openfiremap.org/#17/49.45280/11.07700/voyager`. 책갈피로 저장할 수도 있습니다.

## 상태 상자와 데이터 날짜 {#status}

오른쪽 아래에 확대 단계와 데이터 날짜가 표시됩니다(예: “기준: 1일 전”). “+Sync”는 OpenStreetMap의 최신 변경 사항을 불러왔다는 뜻입니다. “데이터 상태 세부 정보”를 클릭하면 출처, 기준 데이터 날짜와 실시간 업데이트 상태를 볼 수 있습니다. [데이터와 최신성](../data/)에서 더 알아보세요.

## 정보, 법률 및 설정 {#info}

왼쪽 아래의 “정보 및 법률”을 열면 이 도움말, 지도 기호와 오버레이 링크, 법적 고지, 개인정보 보호와 라이선스가 표시됩니다. **로컬 캐시**도 여기서 설정합니다: 끔, 1시간, 1일, 3일, 7일(기본값), 30일. 이미 불러온 영역은 더 빨리 표시됩니다.

## 키보드 사용 {#tastatur}

OpenFireMap은 마우스 없이도 사용할 수 있습니다.

- 첫 번째 <kbd>Tab</kbd>은 “지도 건너뛰기”로 이동합니다.
- 지도에서 화살표 키로 화면을 이동하고 <kbd>+</kbd>, <kbd>−</kbd>로 확대/축소합니다.
- 확대 단계 17부터 <kbd>Tab</kbd>으로 기호를 선택합니다. <kbd>Enter</kbd> 또는 <kbd>Space</kbd>로 세부 정보를 열고 <kbd>Escape</kbd>로 닫습니다.
- 메뉴와 대화상자가 열리면 포커스가 내부에 머뭅니다. <kbd>Escape</kbd>로 닫습니다.
- 내보내기에서 “보이는 영역 사용”을 선택하면 사각형을 그리지 않고 현재 보기를 선택합니다.
