## 어떤 형식을 사용할까요? {#formate}

| 형식 | 결과 | 용도 |
|---|---|---|
| **PNG** | 제목, 축척 막대, 날짜와 출처가 포함된 영역 이미지 | 게시판, 이메일, 발표 |
| **PDF** | 같은 안내도를 PDF로 저장 | 인쇄, 보관 |
| **GPX** | 소화전 및 기타 객체를 경유지로 저장 | 내비게이션, 작전, 야외 앱 |
| **CSV** | 객체별 세부 정보가 있는 표 | 스프레드시트, 분석, 자체 목록 비교 |

내보내기는 컴퓨터에서만 가능합니다. 격자, 거리 색인과 고정 축척이 있는 설계 안내도는 [도시 안내도](../town-plan/)를 사용하세요.

## 단계별 안내 {#ablauf}

:::figure export frame=plain spots=format,select,view,zoom,png,gpx
내보내기 메뉴.
:::

:::steps
1. **내보내기 메뉴 열기:** 왼쪽 위 지도 레이어 옆의 아래쪽 화살표 버튼을 누릅니다.
2. **종횡비 선택 (1):** 자유 영역은 **자유**, A4 비율은 **A4 가로** 또는 **A4 세로**를 선택합니다.
3. **영역 지정:** **지도에서 영역 선택 (2)**으로 사각형을 드래그합니다. **보이는 영역 사용 (3)**은 현재 보기를 선택합니다(A4를 선택하면 A4 비율). 아무것도 지정하지 않으면 현재 보기를 내보냅니다.
4. **세부 수준 선택 (4):** 확대 15~18. 높을수록 세부 정보와 파일 크기가 늘어납니다. 거리는 18, 도시 전체는 16이 적당합니다.
5. **형식 선택:** 소화전 지도는 **PNG (5)** 또는 **PDF**, 소화전 데이터는 **GPX (6)** 또는 **CSV**.
6. **제목 확인:** OpenFireMap이 장소 이름을 넣어 제안합니다. 필요하면 수정하고 **만들기**를 누릅니다.
:::

:::figure title frame=plain
안내도를 만들기 전에 제안된 제목을 수정할 수 있습니다.
:::

생성 중 진행 창에서 현재 작업을 볼 수 있습니다. **작업 취소**를 누르면 언제든 내보내기를 중단합니다.

## 안내도 내용 {#plan}

PNG와 PDF에는 선택 영역, 현재 [배경 지도](../layers/), 모든 소방 객체, 시 경계, 제목, 축척 막대, 날짜, 세부 수준과 “© OpenStreetMap contributors” 출처가 포함됩니다.

파일명에는 날짜, 시간, 세부 수준과 제목이 들어갑니다. 예: `2026-11-19_14-30_Z18_Nuremberg.png`.

:::tip 읽기 쉬운 안내도
내보내기 전에 **인쇄 (Light)** 배경을 선택하세요. 기호가 잘 보이고 잉크도 덜 씁니다. **지형**은 세부 수준 17까지 지원됩니다.
:::

## GPX와 CSV {#gpx-csv}

**GPX**는 각 객체를 이름과 주요 설명이 있는 경유지로 저장합니다. 내비게이션 장치, 작전 앱, OsmAnd와 Garmin BaseCamp 등의 프로그램에서 사용할 수 있습니다.

**CSV**는 세미콜론으로 구분된 표입니다. 각 행에는 유형, 하위 유형, 이름, 참조, 좌표, 지름, 압력, 유량, 주소, 운영자, OSM ID, OpenStreetMap 링크, 데이터 출처와 라이선스가 있습니다. 열 제목은 독일어입니다. Excel, LibreOffice, Numbers에서 바로 열 수 있습니다.

## 제한 {#grenzen}

- **최대 10 × 10킬로미터.** 더 넓으면 브라우저에 과부하가 생길 수 있습니다. 큰 사각형을 그리면 OpenFireMap이 범위를 줄이고 알립니다.
- **확대 단계 15 미만**에서는 지도에 소화전이 표시되지 않습니다. 이 경우 내보내기에서 데이터를 직접 불러오므로 더 오래 걸립니다.
- **컴퓨터 전용.** 스마트폰에는 내보내기 메뉴가 없습니다.
- 영역에 객체가 없으면 “선택한 영역에 객체가 없습니다!”라는 메시지가 표시됩니다.

:::note 출처 표시
데이터는 Open Database License로 제공됩니다. 안내도를 배포하거나 표시할 때 “© OpenStreetMap contributors”가 보여야 합니다. 출처 부분을 자르지 마세요.
:::
