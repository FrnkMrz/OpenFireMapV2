## 배경 지도 {#hintergrund}

:::figure layers frame=plain
컴퓨터의 “지도 레이어” 메뉴.
:::

| 배경 | 용도 |
|---|---|
| **일반 (Voyager)** | 일상적인 사용: 선명한 도로, 확대 단계 17부터 건물 번호 |
| **인쇄 (Light)** | 인쇄 및 내보내기: 밝은 배경에서 기호가 잘 보임 |
| **야간 (Dark)** | 밤이나 차량 안에서 눈부심 감소 |
| **위성 (Esri)** | 현장 방향 확인: 건물, 진입로, 식생 |
| **지형 (OSM)** | 도시 밖의 등고선, 경로와 물길 |
| **OSM (Intl)** | 익숙한 OpenStreetMap 스타일 |
| **OSM (DE Style)** | 독일 스타일의 OpenStreetMap |
| **Bavaria Base** | 바이에른 측량 당국의 공식 지도, 바이에른에서만 |
| **Bavaria Aerial** | 공식 항공 사진, 바이에른에서만 |

선택한 배경은 링크를 공유할 때 유지되며 [내보내기](../export/)에도 사용됩니다.

:::tip 건물 번호 찾기
확대 단계 17과 18에서 일반 및 OSM 지도에 건물 번호가 표시됩니다. 소화전을 주소와 연결하기 쉽습니다.
:::

## 확대 단계 {#zoom}

OpenFireMap은 현재 보기에 필요한 데이터만 불러옵니다. 확대 단계는 상태 상자에 표시됩니다.

| 확대 단계 | 표시 내용 |
|---|---|
| 12 미만 | 아직 객체 없음(상태 “대기”) |
| 12–13 | 점으로 표시된 소방서 |
| 14부터 | 소방서 기호와 시 경계 |
| 15–16 | 색 점으로 표시된 소화전, 급수 지점, 자동심장충격기 |
| 16부터 | 소화전을 탭하면 반경 100미터 원 |
| 17부터 | 문자 기호, 키보드로 선택 가능 |
| 18 | 마우스를 올리면 세부 정보 |

## 색상과 기호 {#symbole}

색상은 객체 종류를, 기호의 문자는 유형을 나타냅니다.

- **빨강:** 소화전. **U**는 지하식, **O**는 지주형, **Ø**는 건식 소화전입니다. 벽면 소화전 등은 별도 기호가 있습니다.
- **파랑:** 소방 연못, 저수조, 소방용 우물, 흡수 지점 등의 급수 시설.
- **초록:** 자동심장충격기(AED).
- **소방서**는 전용 건물 기호로 표시됩니다.

확대 단계 17부터 5미터 안에 여러 객체가 있으면 지도에서 묶어 개수를 표시합니다.

**[지도 기호](/symbols/)** 페이지에서 OpenStreetMap 태그와 함께 모든 기호를 볼 수 있습니다. 기호가 만들어지는 방식을 알고 싶은 매퍼에게도 유용합니다.

:::note 세부 정보의 출처
종류, 지름, 번호 등은 OpenStreetMap에서 가져옵니다. 소화전 유형이 기록되지 않았으면 글자 없는 빨간 점이 표시됩니다. [기여하기](../contribute/)에서 정보를 추가하는 법을 확인하세요.
:::
