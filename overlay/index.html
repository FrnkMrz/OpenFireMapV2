Die Manifestdatei zeigt immer auf das aktuelle Deutschlandarchiv. PMTiles liest einzelne Kacheln per HTTP Range Request; es muss nicht das ganze Archiv in den Browser geladen werden.

Leaflet · Raster-PMTiles

import { PMTiles, leafletRasterLayer } from 'pmtiles';

const manifestUrl = 'https://raster-pilot.openfiremap.org/manifest.json';
const manifest = await fetch(manifestUrl).then(r => r.json());
const archiveUrl = new URL(manifest.file, manifestUrl).href;
const archive = new PMTiles(archiveUrl);

leafletRasterLayer(archive, {
  attribution: '&copy; OpenStreetMap contributors'
}).addTo(map);

Die Rasterkacheln enthalten alle sichtbaren OFM-Inhalte gemeinsam; Einzelschalter gibt es in der Rasterdatei nicht.

MapLibre GL JS · Raster-PMTiles

import maplibregl from 'maplibre-gl';
import { Protocol } from 'pmtiles';

const protocol = new Protocol();
maplibregl.addProtocol('pmtiles', protocol.tile);
const manifestUrl = 'https://raster-pilot.openfiremap.org/manifest.json';
const manifest = await fetch(manifestUrl).then(r => r.json());
const archiveUrl = new URL(manifest.file, manifestUrl).href;

map.addSource('ofm-overlay', {
  type: 'raster',
  url: `pmtiles://${archiveUrl}`,
  tileSize: 256,
  attribution: '&copy; OpenStreetMap contributors'
});
map.addLayer({ id: 'ofm-overlay', type: 'raster',
  source: 'ofm-overlay' });

MapLibre kann Raster-PMTiles als eigene Rasterquelle laden. Für getrennte OFM-Layer wird ein passender Vektor-Datensatz benötigt.

Kachelformat und Abdeckung

  • Koordinatensystem: Web Mercator (EPSG:3857), XYZ-Kachelschema, PNG mit Transparenz.
  • Abdeckung: Deutschland, Zoomstufen 12 bis 18; außerhalb der Abdeckung bleiben Kacheln transparent bzw. leer.
  • Die Archivdatei heißt versionsgebunden. Immer zuerst manifest.json lesen und den Wert file relativ zur Manifest-URL auflösen.
  • Quellenangabe auf der Karte: © OpenStreetMap contributors, ODbL. Die ZIP-Datei enthält zusätzlich ATTRIBUTION.txt.

Klassische {z}/{x}/{y}.png-URLs

PMTiles ist ein Archiv, kein öffentlicher XYZ-Endpunkt. Wer eine URL-Vorlage erwartet, kann das Archiv selbst mit dem PMTiles-Kachelserver bereitstellen, z. B. `pmtiles serve OpenFireMap-Deutschland.pmtiles`. Der Server liefert die einzelnen PNG-Kacheln dann unter einer Z/X/Y-Route aus. Hosting, HTTPS, Cache-Regeln und CORS liegen dabei beim Betreiber.

Browserzugriff und CORS

Der Pilot erlaubt derzeit Browserzugriffe von https://openfiremap.org und http://localhost:5173. Eine fremde Website benötigt eine gezielte Freigabe ihres exakten HTTPS-Origin (Schema und Host, ohne Pfad) im R2-Bucket. PMTiles nutzt Range-Requests; der Server muss GET/HEAD und die benötigten Range-Header sowie passende CORS-Antworten unterstützen. Diese Freigabe ist nicht Teil dieser Umsetzung.

Fehlersuche

  • Leere Kacheln: Zoom 12–18 prüfen, Kartenausschnitt in Deutschland halten und aktuelle Manifestdatei verwenden.
  • CORS-Fehler oder „Failed to fetch“: DevTools-Netzwerk prüfen; der Browser blendet Antworten fremder Origins ohne passende CORS-Freigabe aus.
  • 403/404: Archivdatei aus manifest.json neu lesen statt einen alten, versionierten Dateinamen fest einzutragen.
  • Wenn eigene Domain-Freigabe nicht möglich ist, Archiv selbst hosten oder über den PMTiles-Kachelserver als XYZ ausliefern.
