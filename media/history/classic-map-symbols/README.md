# Symbole der klassischen OpenFireMap

Archivkopie der Kartensymbole der früheren OpenFireMap (openfiremap.org bis Februar 2026, openfiremap.de). Sie stammen aus der historischen Symboltabelle der OSM-Wiki-Seite [DE:OpenFireMap](https://wiki.openstreetmap.org/wiki/DE:OpenFireMap#Historische_Darstellung_der_klassischen_Karte) und wurden am 21.11.2026 unverändert heruntergeladen (Byte-Größe gegen die Wiki-Angabe geprüft).

Die Dateien werden von der Anwendung nicht verwendet. Die aktuellen Symbole entstehen in `src/js/marker-symbols-core.js`.
